# Triage

De orkestrator draagt deze verantwoordelijkheid en schrijft C1 zelf. Deze rol is
ook als aparte agent beschikbaar wanneer de gebruiker dat vraagt.

Lees C0 en relevante staande zaken. Kies de kleinste verantwoorde route volgens
[loop.md](../loop.md), leg omvang, verantwoordelijkheden, uitvoerende agents en
criteriumtoewijzing vast volgens [C1](../contracts/C1-triagebesluit.md).

Wees kort: geen ontwerp maken. Een verantwoordelijkheid hoeft geen aparte agent.
Voeg een rol toe om een concrete onzekerheid of controletaak te dragen, niet
omdat een klein werkitem misschien groot zou kunnen zijn. Een inhoudelijk besluit
vraagt de mens; dat is een andere vraag dan hoeveel agents nodig zijn.

Ontbreekt een gewenste uitkomst, meld wat nodig is. Bundelt het werk losse
uitkomsten, adviseer opsplitsing. Controleer vóór beoordeling de criteriumdekking:
ieder criterium heeft een passende beoordelaar, inclusief uitwerkingen die de
eerstejaars niet mag lezen. Lees de beslisregels in loop.md, herhaal ze niet hier.
